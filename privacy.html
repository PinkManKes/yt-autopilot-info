Privacy Policy

Last updated: 2026-07-01. Effective from: 2026-07-01.

Overview

YT Autopilot ("the Tool") is a personal automation tool that operates locally on the developer's own hardware. It uses the YouTube Data API v3 solely to upload videos to the authenticated user's own YouTube channel. This policy explains what data is handled and how.

Data collected and used

DataPurposeStorageSharing
Google OAuth refresh token To obtain short-lived access tokens for YouTube video upload operations only Local file (~/yt-autopilot/pipeline/config/yt_token.json) with owner-only read permission (chmod 600) Never shared. Only transmitted to Google's own OAuth endpoints.
Google account email (from OAuth) Displayed only during OAuth consent; not stored by the Tool Not stored beyond the OAuth session Never shared

Data the Tool does NOT collect

  • User contacts, calendars, drive files, or any other Google service data
  • YouTube analytics, subscribers, comments, or watch history
  • Any other user's channel or content
  • Personal information beyond what OAuth provides for the requested scope

Scope and authorization

The Tool requests the following OAuth scope:

  • https://www.googleapis.com/auth/youtube.upload — required for uploading videos.
  • https://www.googleapis.com/auth/youtube.force-ssl — required for attaching subtitles to uploaded videos.

No other scope is requested. The Tool will not attempt to access data outside these scopes.

Data storage location

All data (source video files, generated assets, OAuth tokens) is stored locally on the developer's own machines. No cloud storage, no third-party server, no external data pipeline is involved. The Tool does not have a backend service.

Data transmission

The only external transmissions the Tool makes are:

  • To Google's OAuth endpoints (oauth2.googleapis.com) — for token operations.
  • To YouTube's video upload endpoints (www.googleapis.com/upload/youtube/v3) — for uploading the video file.
  • To Pexels API (api.pexels.com) — for downloading royalty-free stock footage used in generated videos. This transmission does not include any Google user data.

Data retention and deletion

The Tool retains OAuth tokens only for as long as they are useful. To delete all stored data, the user can:

  1. Delete the token file: rm ~/yt-autopilot/pipeline/config/yt_token.json
  2. Revoke the app's access in the Google Account settings: myaccount.google.com/permissions

Children

The Tool is not directed at children under 13 and does not knowingly collect personal information from children.

Changes to this policy

Any changes to this policy will be posted here with an updated "Last updated" date. Material changes will require the user to re-authorize the Tool.
