YT Autopilot

A personal automation tool for content creators that schedules and publishes videos to your own YouTube channel on a regular cadence.

Status: Personal use by developer. Source is not currently distributed publicly.
Scope requested: youtube.upload (and read scopes for verification)
Contact: ai.leverage10 [at] gmail.com

What it does

YT Autopilot is a workflow tool that automates the tedious parts of maintaining a scheduled content calendar on YouTube:

  • Generates video assets (voice narration, stock footage assembly, thumbnails) from a script file the creator writes.
  • Uploads the assembled video to the creator's own YouTube channel using the YouTube Data API.
  • Sets a scheduled publish time (publishAt) so videos go live at a consistent cadence.
  • Runs on a schedule (every two weeks) so the creator does not have to remember to upload.

The tool is used by the developer to maintain a personal Claude Code tutorials channel with a regular posting cadence.

Why the youtube.upload scope

The tool needs to upload finished video files to the authenticated user's YouTube channel. That requires the https://www.googleapis.com/auth/youtube.upload scope. No other write scope is used.

What data the tool reads

APIPurpose
videos.insertUpload video file + set metadata (title, description, tags, publishAt)
captions.insertAttach multilingual subtitles to uploaded videos (when applicable)

What data the tool does NOT touch

  • Any other user's channel or videos
  • Comments, playlists, subscriptions, or analytics
  • Personal information beyond the OAuth token issued for upload

How OAuth is used

  1. The user runs a local command bash auth_youtube.sh.
  2. The browser opens the standard Google OAuth consent page.
  3. The user grants youtube.upload scope.
  4. The tool stores the refresh token in a local file with chmod 600 permissions (owner read-only).
  5. The tool uses the refresh token to request access tokens for upload operations only.
  6. The token is never transmitted anywhere except to Google's own OAuth endpoints.

Deployment

The tool runs on the developer's own hardware (Mac and Windows machines on a private LAN). No cloud service, no third-party server, no data hosting. All processing is local.
